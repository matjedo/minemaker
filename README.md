# Mine Maker

## pt-br
**Dependências:**
Python

**Como usar:**
Abra o arquivo `main.py` no Visual Studio Code.
Mantenha o arquivo `file_manager` aberto no VS Code para gerenciamento de arquivos.
Comece a configurar pelo `main.py`.
Utilize as teclas do seu teclado (1–7) para configurar!

## en-us
**Dependencies:**
Python

**How to use:**
Open the `main.py` file in Visual Studio Code.
Keep the `file_manager` file open in VS Code for file management.
Start configuring using `main.py`.
Use the number keys on your keyboard (1–7) to configure!
